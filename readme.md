README – Retos de Estructuras de Datos y Comprehensions en Python
Descripción

Este repositorio reúne cinco retos desarrollados en Python con el objetivo de fortalecer el manejo de las principales estructuras de datos del lenguaje. A lo largo de los ejercicios se aplican listas, tuplas, diccionarios, conjuntos (sets) y comprehensions para resolver problemas prácticos relacionados con inventarios, catálogos, ventas y análisis de información.

Cada reto está diseñado para poner en práctica conceptos fundamentales de programación, como funciones, ciclos, condicionales y operaciones sobre colecciones de datos.

Objetivo

Construir un sistema de inventario utilizando listas anidadas para administrar productos, cantidades y precios.

Funcionalidades implementadas
Definición del inventario mediante listas.
Actualización del precio de un producto.
Registro de ventas descontando el stock disponible.
Agregar nuevos productos o aumentar el stock de productos existentes.
Mostrar el estado completo del inventario.
Aprendizajes

Durante este reto se comprendió cómo almacenar varios datos relacionados dentro de una lista, recorrer estructuras anidadas y modificar sus valores mediante funciones.
